1. Vacuum & Cleanup

Removes dead tuples, reclaims storage, and updates planner statistics.

VACUUM ANALYZE;

2. Check Table Sizes

Displays total disk space usage for all user tables including their indexes.

SELECT relname AS "Table", 
       pg_size_pretty(pg_total_relation_size(relid)) AS "Size"
FROM pg_catalog.pg_statio_user_tables
ORDER BY pg_total_relation_size(relid) DESC;

3. Active Connections

Lists all currently running sessions and queries execution states.

SELECT pid, usename, client_addr, state, query 
FROM pg_stat_activity 
WHERE state != 'idle';
